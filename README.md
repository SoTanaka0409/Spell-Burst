# Spell Burst

DxLibを使用したC++弾幕アクションゲームプロジェクトです。

## フォルダ構成

- `Source/`: ゲーム本体のC++ソースコード。
- `Resource/assets.csv`: 素材IDとファイルパスの対応表。
- `Resource/Runtime/`: 実行時に読み込む素材。
- `Resource/SourceAssets/`: 制作・編集元として保管する素材。
- `Docs/`: 作業メモや整理方針。
- `Logs/`: ログファイル。
- `Tools/`: 補助スクリプトや退避した検証用ファイル。

素材を追加・移動した場合は、`Resource/assets.csv` のパスも合わせて更新してください。
