# Spell Burst
自作コリジョン演算と状態遷移モデルによる、C++製弾幕アクションゲームです。
アイテム収集などの要素を削ぎ落とし、「精密な弾幕回避」と「ボスの行動パターンの見極め」に特化しました。
## 概要 
- **ジャンル**：弾幕アクション
- **プラットフォーム**：PC (Windows)
- **開発環境 / 言語**：C++ / DxLib
- **開発規模**：個人制作（1名）
## 技術的なアピールポイント 
弾幕ゲームの根幹である「厳密で理不尽のない当たり判定」と「拡張性の高いボスAI」の設計に注力しました。
* **数学計算に基づく当たり判定処理の自作**
  * ライブラリの矩形判定に依存せず、キャラクター形状に合わせた「円判定」や、移動軌跡を考慮した「カプセル判定」を独自実装。高速移動時のすり抜け現象を防ぐ正確なコリジョンを実現しました。
* **Stateパターンの導入によるAI設計（ボス行動管理）**
  * ボスの行動管理において、単一クラスでの分岐処理の肥大化を防ぐためStateパターンを採用。待機状態や各種攻撃パターンを独立したクラスとして設計し、拡張性の高いコードベースを構築しました。
* **状態遷移モデルを用いた難易度設計**
  * ボスの体力残量や経過時間に応じた状態遷移モデルを構築。極太レーザーや追従弾など、挙動の異なる攻撃クラスを動的に組み合わせることで、単調にならない戦闘バランスを実現しています。
* **プレイヤー体験を向上させるシステム実装**
  * 弾幕回避に集中させるための「オート連射機能」や、ミリ単位の操作を可能にする「低速移動（Shiftキー）システム」を実装しました。
