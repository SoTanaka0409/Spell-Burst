## 💡 コンセプト・ゲーム概要

アイテム収集などの付随要素を削ぎ落とし、精密な弾幕の回避、自機の成長、ボスの行動パターン攻略に特化した弾幕アクションゲームです。

- **3つの機体タイプと必殺技**:
  - 標準タイプ（極太レーザー：高威力の直線攻撃）
  - 拡散タイプ（虹色ウェーブ：敵弾を相殺・反射するバリア波）
  - 追尾タイプ（桜吹雪：画面全体に展開する誘導弾）
- **成長とゲームサイクル**:
  - 道中の敵を倒して経験値を獲得し、レベルアップで通常弾数を強化。通常攻撃はオート連射化し、プレイヤーが回避と必殺技の判断に専念できる設計にしました。
- **ボスの多段階弾幕バトル**:
  - ボスの体力ゲージや経過時間に応じて攻撃パターンが変化。多種多様な弾幕アルゴリズムに対応する達成感を重視しています。

## 🛠 技術的なこだわり・アピールポイント

### 1. 2D上の弾幕の軌道計算の実装と負荷調整
- **取り組んだ理由**:
  - 単調な直線弾だけでなく、波状や放射状など多彩で見た目にも楽しめる弾幕の軌道を自作したいと考え挑戦しました。
- **工夫した点・実装内容**:
  - 数式や軌道の作り方について一部AIを活用して調べながら、2D平面上での弾の移動計算を組み上げました。
  - 大量の弾を生成してもゲームがクラッシュや処理落ちを起こさないよう、画面内に出現させる弾の総数を計算して適切な量に調整しました。

### 2. 飽きさせないための難易度とゲームテンポづくり
- **取り組んだ理由**:
  - 単純な繰り返し作業にならず、プレイヤーが最後まで集中して楽しめるゲームテンポを作るために設計しました。
- **工夫した点・実装内容**:
  - ゲームの進行度や敵を倒す速度に合わせて、弾幕の密度やボスの行動変化のテンポが早くなるように難易度を調整しました。
  - 自機の成長による殲滅力の爽快感と、激しくなる弾幕を避ける緊張感のバランスを取り、飽きずに挑戦し続けられるゲーム体験を目指しました。

## 🔧 課題と問題解決

| 直面した問題 | 原因 | 解決策（アプローチ） |
| :--- | :--- | :--- |
| **被弾時の即死や、敵の当たり判定が一時的に消失するバグ** | 実装時にAIを活用してコードを取り入れた際、既存のプロジェクトの処理や変数を意図せず上書きしてしまい、判定フラグやダメージ計算の整合性が崩れていた。 | Gitのコミットを機能・修正ごとに細かく行い、差分を正確に追跡できるように運用を改めた。また、発生したバグの内容と原因をメモとして記録・蓄積することで、コードの競合や予期せぬ上書きを早期に防ぎ、迅速に原因を特定して解消できるようにした。 |
